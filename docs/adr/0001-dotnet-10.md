# ADR-0001: Target .NET 10 (LTS)
Date: 2026-11-11 · Status: Accepted
## Context
.NET 8 and .NET 9 reach end of support on 10 Nov 2026. A new project should not start on an expiring runtime.
## Decision
All services target `net10.0`; `global.json` pins SDK 10.0.x (`rollForward: latestFeature`). Packages that track .NET are added with `--version "10.*"` so NuGet never hands us an 11.x build.
## Alternatives
- .NET 8: most tutorials, but unsupported tomorrow.
- .NET 11 (Nov 2026): STS, shorter support than 10.
## Consequences
+ Supported until Nov 2028. − Must watch version wildcards now that .NET 11 packages are on NuGet.
